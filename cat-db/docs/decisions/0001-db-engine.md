# 0001. DB 엔진 선택

- 날짜: 2026-10-01
- 상태: 제안

## 배경
태그 기반 조건 조회(SQL)와 LLM 연동이 필요하다. 파일럿은 빠르게 반복해야 하고, 운영 단계에서는 컨설턴트 여러 명이 접근하고 자동 적재가 돌아야 한다.

## 선택지
1. **SQLite** — 설치 불필요, 파일 하나로 반복 실험이 쉬움. 다중 사용자/권한 관리는 약함.
2. **Supabase(Postgres)** — 이미 내부 시스템이 사용 중. RLS 권한, 웹 UI, 정기 작업(Edge Function) 활용 가능. pgvector로 전사본 의미 검색 확장 가능.
3. 1 → 2 단계적 전환.

## 결정 (제안)
3번. 1·2단계 파일럿은 SQLite로 구조를 빠르게 다듬고, 3단계에서 Supabase로 이전한다. 두 DB 모두에서 돌아가도록 DDL은 표준 SQL 위주로 작성한다.

1단계에서 샘플을 본 뒤 확정한다.
