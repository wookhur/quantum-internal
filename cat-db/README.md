# CAT 자료 DB

컨설턴트들이 축적한 CAT 자료를 태그 기반으로 DB화해서, 조건별 사례 조회 → LLM 분석/보고서 작성에 활용하기 위한 프로젝트입니다.

- 원본: 구글 드라이브 등 기존 위치에 그대로 보관
- DB: 원본 위치 + 학생(가명) + 프로젝트 + 태그 + 시점별 성과
- 확장: 웨비나 녹음, 인스타 영상 전사본도 같은 구조로 수용

프로젝트 규칙과 현재 진행 상태는 [CLAUDE.md](./CLAUDE.md), 작업 이력은 [docs/WORKLOG.md](./docs/WORKLOG.md)를 참고하세요.
